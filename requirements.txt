# Python 3.13-compatible adaptation of requirements.txt
#
# The original Code Ocean environment targets Python 3.9 (miniconda3 4.12.0).
# This container only provides Python 3.13 (no Docker, no gcc to build from
# source), so a few pins that have no cp313 wheels are adjusted:
#
#   * pandas 2.2.1 -> 2.2.3   (2.2.1 has no cp313 wheel; 2.2.3 is API-compatible)
#   * pvlib 0.10.4 -> 0.11.0  (0.10.4 uses np.Inf, removed in NumPy 2; NumPy <2
#                              has no cp313 wheel, so NumPy 2.x is required on
#                              Python 3.13, which forces pvlib >= 0.11.0)
#   * numpy / matplotlib / Pillow / kiwisolver left unpinned so pip picks
#     versions that ship cp313 wheels.
#
# All pure-python pins are kept identical to the original (cycler, pyparsing,
# python-dateutil, six, simpy, pvlib).
