# Wireless extension: analysis data

`metrics.csv` and `rankings.csv` contain the exploratory wireless experiment:
two scenarios, three strategies and three seeds (18 runs). `references/`
contains the frozen scenario scoring bounds. This exploratory experiment is
distinct from the wired supplementary ablation.

Database paths are historical identifiers; raw simulation databases are not
included. Source: `扩展实验/最终分析结果/` in the local experiment archive.
Files are copied without changing their contents.
