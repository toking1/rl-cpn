# Weight-adjustment and placement comparisons: analysis data

`final/` holds per-method metrics, rankings and frozen references for the
formal comparison: nine methods, four scenarios and five paired seeds (180
runs). `tune/screen/` and `tune/valid/` contain parameter-selection and
validation results; these are not part of the formal test count. Scenario
reference files are also retained at `final/references/`.

Database paths are historical identifiers; raw simulation databases are not
included. Source: `对照实验/最终分析结果/` in the local experiment archive.
Files are copied without changing their contents.
