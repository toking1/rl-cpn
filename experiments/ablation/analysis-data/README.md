# Ablation experiments: analysis data

`metrics.csv` and `rankings.csv` contain the main ablation analysis: four
scenarios, ten configurations and ten seeds (400 runs). `supplementary-ablation/` contains
the separate supplementary ablation: four additional configurations, four
scenarios and the same ten seeds (160 runs). Do not count these as new seed
groups. `references/` holds the frozen scoring bounds; `local-analysis/` contains
additional derived summaries.

Directory names are normalized to English; archived data contents and
historical execution paths are unchanged.

Database paths are historical identifiers; raw simulation databases are not
included. Source: `消融实验/最终分析结果/` in the local experiment archive.
Files are copied without changing their contents.
